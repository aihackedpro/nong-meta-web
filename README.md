## 📲 ติดตั้งลงเครื่องเป็นแอป (PWA — ไม่ต้องผ่าน App Store)

เปิดลิงก์ด้านบนในเบราว์เซอร์ แล้ว:

- **iPhone / iPad (Safari):** แตะปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)** → ได้ไอคอน **META** เปิดเต็มจอเหมือนแอป
- **Android (Chrome):** แตะเมนู ⋮ → **ติดตั้งแอป / เพิ่มลงในหน้าจอหลัก**
- **macOS (Safari):** เมนู **ไฟล์ → เพิ่มไปยัง Dock** — หรือ **Chrome:** ไอคอนติดตั้งบนแถบที่อยู่

ติดตั้งแล้วเปิดใช้แบบออฟไลน์ได้ (แคชด้วย Service Worker)

> Repository นี้เก็บเฉพาะไฟล์เว็บที่ build แล้ว ส่วน source อยู่ในโปรเจกต์หลัก `nong-meta`
